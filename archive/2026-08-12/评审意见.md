## 我的判断

**这个方向值得做，但不应该继续被包装成“给材料领域模型加一个 memory 模块”。**
更有价值的定位是：

> **在计算预算和存储预算均受限的科学发现过程中，系统应该保留哪些历史观测，才能真正改善未来的实验选择与科学决策？**

这和“训练一个专业领域大模型”不是一回事。你的 MATMEM 使用的是**冻结的材料预测器**，研究的是如何选择、迁移和使用历史残差，以减少后续稳定材料筛选中的错误；它已经比“训练一个会读论文的材料大模型”更接近真实科学问题。论文里关于因果凸包、协议兼容、false-stable 成本和有界 memory 的动机本身是成立的。

但是，**当前版本还容易被顶会审稿人认为是一个精心设计的工程系统**：

> compatible kNN residual correction
>
> * metadata/protocol gate
> * greedy coreset
> * conformal calibration
> * abstention

每个部分都合理，但尚缺少一个足够集中的、不可由常规模块替代的核心学习问题。

另外需要说明时间范围：截至 **2026 年 7 月 15 日**，ICLR 2026 和 ICML 2026 的论文已经可以纳入调研，但 NeurIPS 2026 要到 **2026 年 9 月 24 日**才通知录用，所以目前能可靠参考的是 **NeurIPS 2025**，不能声称已调研 NeurIPS 2026 录用论文。([ICLR][1])

# 一、2025–2026 顶会正在怎样重新定义“Memory”

## 1. Memory 的创新点已经不再是“存什么格式”

ICLR 2025 的 **NAMM** 不再使用人为规定的 FIFO、LRU 或 attention threshold，而是训练一个可以跨模型、跨任务迁移的 memory manager，学习哪些历史状态值得保留。NeurIPS 2025 的 **A-Mem** 也强调记忆之间的动态链接、组织和演化，而不是把经验简单写入向量库。ICML 2026 的 **PlugMem** 则进一步关注如何把原始经历压缩为高信息密度、任务无关的知识结构。([ICLR 会议录][2])

这对 MATMEM 的启示是：

**你现在的 memory utility 是人工定义的。**

当前卡片价值近似为：

[
\Delta_i(M)=R_t(M)-R_t(M\cup{i}),
]

但其中的局部风险、候选池和权重都是人为规定的。审稿人很可能追问：

* 为什么这个 risk surrogate 就能代表未来价值？
* 为什么近期 candidate pool 可以代表未来分布？
* 为什么近凸包残差一定比结构新颖性、协议覆盖或化学复现性更重要？
* memory 的价值为什么不从历史发现轨迹中学习？

因此，“再设计一个更复杂的打分函数”不够学术化。更好的问题是：

> **能否从闭环发现轨迹中学习一个 memory value function，使它预测一条观测在未来若干轮中能够减少多少决策 regret？**

---

## 2. Memory 正从语言模型扩展为普遍的测试时计算资源

ICLR 2025 的 **EM-LLM** 在不微调模型的条件下，以事件边界和 surprise 组织长期记忆；NeurIPS 2025 的 **Agentic Plan Caching** 把 memory 用来减少测试时调用成本，而不只是提升准确率；NeurIPS 2025 的 **MEMENTO** 更直接表明，memory 可以用于组合优化和序贯决策，而不局限于语言任务。

这实际上支持你的方向：

**MATMEM 不需要变成一个材料 LLM 项目。**

它更适合被描述为：

> Memory as a bounded test-time computational resource for sequential scientific decision-making.

真正需要证明的不是“模型记得更多以后 MAE 下降了”，而是：

* 相同 DFT 预算下发现更多稳定材料；
* 相同 discovery recall 下浪费更少的 DFT 计算；
* 相同 memory 容量下取得更低的 cumulative decision regret；
* 在协议变化和凸包更新时知道哪些记忆已经失效。

---

## 3. 最新 coreset 工作开始重视“记忆变旧”

NeurIPS 2025 的 **ERACS** 明确研究了 coreset 的 representativeness 会随数据分布变化而退化，因此不仅要选择 coreset，还要判断它何时已经陈旧、何时需要重新选择。NeurIPS 2025 的在线两阶段子模优化工作则把在线选择、约束和 approximation regret 放入统一理论框架。

而 MATMEM 当前主要考虑：

* 新卡片是否值得加入；
* 旧卡片是否被新卡片替代。

但尚未充分区分三种“失效”：

1. **分布失效**：未来候选进入新的化学空间；
2. **协议失效**：DFT 设置或数据源发生变化；
3. **科学状态失效**：新的竞争相进入凸包，原来的 near-miss 已不再靠近边界。

因此，memory staleness 很可能成为你比普通 agent memory 更独特的创新点。

---

## 4. 科学发现前沿正在转向联合序贯决策

近两年的 BO 和 active learning 工作不再只问“下一个点选谁”，还开始考虑：

* 初始化数据应该怎样选择；
* 多步 lookahead；
* 实验什么时候值得停止；
* 廉价虚拟评估和昂贵真实实验如何联合；
* 当现有科学假设解释不了异常时，搜索空间或原则本身是否应该演化。

ICML 2025 已出现 informed initialization、multi-step BO 和 calibrated prediction 方向；ICML 2026 的 **Cost-aware Stopping**、**LABO** 和 **PiEvo** 分别研究实验成本、廉价模拟与昂贵实验的联合，以及科学原则空间的演化。([Proceedings of Machine Learning Research][3])

相比之下，你当前 MATMEM 的 oracle schedule 是固定的：

> 候选已经决定要做 DFT，MATMEM 只在结果出来后决定是否记住它。

这意味着它还不是完整的 closed-loop discovery。真正的闭环应该联合回答：

1. **下一次计算哪个材料？**
2. **计算完成后保留哪条信息？**
3. **什么时候不值得继续计算？**
4. **什么时候已有 memory 已不足以支持当前协议或化学空间？**

---

## 5. “强通用模型 + 测试时适应”比重新训练窄领域模型更合理

NeurIPS 2025 的 **UMA** 展示了一个覆盖大量元素、任务和原子体系的通用原子模型，在不针对每个任务单独微调的情况下，也可以达到或超过不少专用模型。它不是语言模型，但它说明了材料科学建模中的一个重要趋势：**先获得强而广泛的冻结基础模型，再用推理期机制处理任务、协议和分布变化。**

所以你听到的“训练专业领域大模型效果不一定好”，不意味着你的方向没有价值。更准确地说：

* 不建议训练一个新的“材料论文 LLM”作为核心贡献；
* 不建议把创新建立在“模型参数记住更多领域知识”上；
* 可以使用 UMA 等强通用模型作为 frozen predictor；
* 把研究重点放在**有限观测如何在真实科学决策中被组织、压缩和复用**。

# 二、当前 MATMEM 为什么仍可能被认为偏工程

| 当前设计                      | 审稿人可能的质疑               | 学术化升级                                  |
| ------------------------- | ---------------------- | -------------------------------------- |
| 残差 memory cards           | 为什么不是带 metadata 的 kNN？ | 定义有限 memory 下的序贯决策问题和 regret           |
| 人工风险效用                    | 又一个手工 eviction score   | 学习未来价值，或给出与真实目标一致的理论                   |
| 固定 oracle schedule        | 并没有控制发现过程              | 联合决定 query 和 retention                 |
| 协议 fingerprint gate       | 工程规则很多                 | 建立可学习、可校准的协议迁移图                        |
| affine protocol transport | 表达能力有限                 | robust GP、层次残差模型或因果 transport          |
| split conformal           | temporal drift 下保证很弱   | anytime/online 风险控制                    |
| causal hull snapshots     | 很有材料特色，但主要是审计机制        | 发展 boundary-preserving hull coreset 理论 |
| 无真实结果                     | 无法证明实际意义               | 先做强 falsification pilot，再扩展方法          |

其中最严重的三个问题是：

### 1. 当前保证没有对齐最终目标

论文给出的 (1-1/e) 保证只对应 pointwise-max surrogate，并不直接保证：

* 稳定材料发现数量；
* false-stable 数量；
* discovery regret；
* DFT 成本。

这类“在自己设计的 surrogate 上有保证”很容易被认为形式正确但意义有限。

### 2. 当前不是完整闭环

论文标题强调 closed-loop discovery，但候选查询过程并没有由方法控制。审稿人会问：

> 如果不能决定下一次 DFT 做谁，为什么称为 closed-loop discovery，而不是 online residual calibration？

### 3. Protocol-aware 现在更像规则系统

记录 functional、Hubbard-(U)、pseudopotential 和 relaxation protocol 很科学，但单纯定义 exact match、affine transport、otherwise abstain，容易被认为是严谨的数据工程，而不是机器学习贡献。

# 三、我建议的三个学术化方向

## 方向一：联合“实验选择”和“记忆保留”

### Joint Acquisition and Retention under Dual Budgets

这是我认为**顶会潜力最高**的升级。

令每一轮同时执行两个动作：

[
a_t=(q_t,e_t),
]

其中：

* (q_t)：选择哪个候选进行 DFT；
* (e_t)：oracle 返回后，选择写入、合并或删除哪条 memory。

约束为：

[
\sum_t C(q_t)\leq B,\qquad |M_t|\leq K.
]

目标不再是局部 residual risk，而是最小化：

[
\mathcal R_T =
\sum_{t=1}^{T}
\left[
c_{\mathrm{FS}}\mathbf 1(\hat s_t=1,s_t=0)
+
c_{\mathrm{FU}}\mathbf 1(\hat s_t=0,s_t=1)
+
\lambda C(q_t)
\right].
]

### 可以形成的核心贡献

1. 提出同时具有 **oracle budget (B)** 和 **memory budget (K)** 的科学发现问题；
2. 提出 acquisition-retention 联合策略；
3. 给出相对于 full-history policy 或最优有限 memory policy 的 regret；
4. 研究 memory 容量和实验预算之间的 trade-off；
5. 证明什么时候 memory 有用，什么时候应该花预算重新计算。

### 为什么比当前版本更有意义

memory 不再只是修正预测，而会改变后续实验序列：

> 因为记住了某类 near-miss，系统不再反复浪费 DFT 预算在同类假稳定材料上。

这才是可以说“加速科学发现”的因果链条。

---

## 方向二：边界保持型科学 Memory

### Boundary-Preserving Memory for Dynamic Phase Diagrams

这是**数学问题最干净、最不像工程系统**的方向。

你的真正目标并不是重构全部历史残差，而是保持稳定性边界附近的决策。因此可以定义：

> 在容量 (K) 下，寻找最小 memory，使其对未来候选的 stable/unstable 决策与 full-history memory 尽可能一致。

例如要求：

[
\Pr_{x\sim P_t}
\left[
\operatorname{sign}\big(\hat h_{M_t}(x)-\tau\big)
\neq
\operatorname{sign}\big(\hat h_{\mathrm{full}}(x)-\tau\big)
\right]
\leq \epsilon.
]

或者更材料化地定义：

* 哪些相必须保留，才能近似保持当前凸包；
* 哪些 residual witnesses 必须保留，才能保持凸包附近 ranking；
* 新相进入后，原 memory 中哪些点变成冗余或失效；
* 在给定化学系统维数和误差容忍度下，需要多少 memory。

### 可能得到的理论结果

* boundary-preserving coreset 的充分条件；
* memory 大小与 (\epsilon)、候选覆盖和成分空间维度之间的关系；
* 任意算法所需容量的下界；
* 凸包修订时的增量更新复杂度；
* 对 near-hull decision 而非全局 MAE 的 approximation guarantee。

这比“选择风险最大的卡片”更容易形成一个清晰的理论对象。

---

## 方向三：协议图上的可校准 Memory Transport

### Calibrated Memory Transport across Scientific Protocols

把不同的 DFT functional、Hubbard-(U)、pseudopotential、代码版本和实验测量流程看作协议节点：

[
c_1,c_2,\ldots,c_m.
]

在协议之间学习有向 transport：

[
T_{i\rightarrow j}(r,x),
]

同时估计：

* transport bias；
* heteroscedastic uncertainty；
* support overlap；
* cycle inconsistency；
* transport 是否值得使用。

最终系统执行：

[
\text{reuse},\quad \text{transport},\quad
\text{new oracle query},\quad \text{abstain}
]

四选一，而不是目前的 exact match / affine map / reject。

NeurIPS 2025 的 computation-aware robust GP 说明，近年的方法已经开始联合考虑近似计算产生的不确定性和异常观测，这可以成为你做 protocol transport 的理论工具之一。([NeurIPS 会议论文集][4])

这个方向的优点是材料特色强，而且可以扩展到：

* 不同实验室；
* 不同测量仪器；
* 不同模拟精度；
* 低保真到高保真计算；
* 数据库版本迁移。

但它比前两个方向更依赖跨协议真实匹配数据，数据获取风险也更高。

---

# 四、最推荐的最终组合

我不建议把三个方向全部塞进一篇论文。那样又会变成“系统模块很多，但中心贡献模糊”。

最合理的是：

## 主贡献：方向一

**Joint acquisition and retention under oracle and memory budgets**

## 核心算法：方向二

**Boundary-preserving memory coreset**

## 现实挑战与实验场景：方向三的一部分

**Protocol shift + calibrated abstention**

可以将论文重新概括为：

> We study closed-loop scientific discovery under two coupled resource constraints: a finite oracle budget and a finite memory budget. Rather than retaining observations that minimize reconstruction error, we maintain a boundary-preserving memory that jointly guides future experiment acquisition and controls false-stable decisions under protocol shift.

候选标题可以是：

* **Learning What to Retain for Closed-Loop Scientific Discovery**
* **Boundary-Preserving Memory for Budgeted Materials Discovery**
* **Joint Experiment Selection and Bounded Memory under Scientific Protocol Shift**
* **Causal Scientific Memory under Oracle and Storage Budgets**

# 五、必须先做的 falsification 实验

在继续写完整方法之前，我建议先判断 memory 是否真的存在有效信号。

## Gate 1：历史残差是否具有可复用性

对真实 chronological 或模拟 chronological stream，计算：

* residual 的结构邻域相关性；
* 相同 composition/prototype 下的相关性；
* 距离随时间增长后的相关性；
* 同协议与跨协议相关性的差异；
* near-hull 区域是否比全局区域更相关。

如果局部历史 residual 对未来 residual 没有预测能力，任何 memory policy 都没有意义。

## Gate 2：强 compatible kNN 能否已经解决问题

必须包含：

* full history；
* compatible kNN；
* FIFO；
* reservoir；
* k-center/diversity；
* residual-priority；
* staleness-aware refresh；
* 你的方法。

如果 MATMEM 不能在匹配 coverage、memory 和 DFT budget 下稳定超过 compatible kNN，那么当前复杂设计没有必要。

## Gate 3：memory 是否会改变发现轨迹

不能只报告 formation-energy MAE。至少报告：

* cumulative true discoveries；
* cumulative false-stable DFT calls；
* discovery regret；
* discovery recall at fixed cost；
* cost per true stable discovery；
* risk–coverage curve；
* 每条 retained memory 节省的 oracle cost。

## Gate 4：证明 memory 不是永远有效

设计三类负对照：

* residual 独立同分布且不可预测；
* 化学空间完全不复现；
* 协议变化但不存在可靠 transport。

正确的方法在这些情况下应该退化到 base-only、重新查询或 abstain，而不是继续声称 memory 有帮助。

这一类“何时 memory 不应被使用”的结果，反而会提高论文可信度。

# 六、对“这个方向究竟值不值得做”的最终回答

**值得，但要改变研究中心。**

不建议继续做成：

> 给材料预测模型外挂一个带协议字段的 residual memory，然后设计若干检索与淘汰规则。

建议做成：

> 研究有限 memory 如何作为一种科学资源，与实验预算共同决定闭环发现过程，并围绕动态稳定边界给出新的算法、理论和真实验证。

你的工作真正有意义的地方不是“使用了 memory”，而是它可能回答一个长期存在但没有被明确形式化的问题：

> **科学发现不断产生新的观测，但我们不可能永久保存、重新处理和同等信任所有历史信息。有限资源下，哪些观测值得成为未来科学决策的依据？**

这比训练一个专业领域大模型更普遍，也能够迁移到药物筛选、催化剂发现、分子设计、多保真仿真和实验室自动化。

我目前最推荐你优先验证的路线是：

> **Joint acquisition–retention + boundary-preserving memory。**

只要这个方向能在强 compatible kNN 和 BO 基线之上，表现出明确的 cumulative discovery 或 regret 优势，它就不再是一个普通工程 memory 模块，而会成为一个相对独立的序贯学习问题。
