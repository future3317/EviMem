## 结论

这次修改是**实质性升级**，不是把旧 MATMEM 换一个名字。现在的论文已经具备了一个清楚的研究对象：

> 有限候选池中，在 oracle 预算 (B) 和活跃 residual memory 容量 (K) 下，查询与保留决策如何相互影响。

在线量与未来 oracle 标签也已经分离，负结果没有被隐藏，论文明确承认 joint 只在 retention competition 场景成立，在 recurrence、IID 和无复现条件下并无普遍优势。 

但我不会认为它已经“整体修正完成”。当前版本仍有四个可能导致直接拒稿的核心问题：

1. (K) 的科学含义不够成立；
2. Eq. 11 的 information gain 混入了候选自身被移出池子的收益；
3. Proposition 1 在目前形式下虽然条件正确，但比较意义弱、regret bound 近乎空洞；
4. residual interval 并不能自动定义一个有概率意义的两点分布。

其中第 2 点很可能同时对应一个代码级目标函数错误。

---

# 一、首先修正 (K) 的定义：它不是“存储容量”

论文说系统只能保留 (K) 个历史 oracle 结果，但同时又永久持有：

[
U_t={\text{所有剩余候选结构、embedding、协议、冻结预测}}.
]

这意味着系统并不是总体 bounded-memory；它只是限制了**参与在线校正的 residual witnesses 数量**。而且材料计算中的单个 formation energy 和协议记录很小，直接删除昂贵 DFT 结果在现实中不太合理。

这会让审稿人追问：

> 为什么不能保存全部 DFT 结果，再用 ANN 或局部检索选出当前需要的若干条？

已有 bounded-memory active learning 的定义通常真的限制学习者能够保存或访问的数据，而你的 pool 始终完全可见，因此不能把两者等同。([Proceedings of Machine Learning Research][1])

### 更合理的改法

把 (K) 从 `memory capacity` 改成：

> **certified active witness budget / working-set capacity**

即：

* 所有 oracle 结果可以进入不可变 audit archive；
* 每轮最多激活 (K) 个经过协议检查、凸包版本检查和索引处理的 residual witnesses；
* 激活、验证和检索它们具有延迟或计算成本；
* retention 决定 active working set，而不是决定是否销毁科学数据。

状态写成：

[
S_t=(U_t,A_t,M_{t-1},H_t,b_t),
]

其中 (A_t) 是完整历史 archive，(M_t\subseteq A_t)、(|M_t|\le K) 是在线工作集。

这样论文回答的是：

> 有限测试时计算和认证预算下，哪些历史结果值得进入当前决策状态？

而不是“不现实地遗忘昂贵 DFT 结果”。

# 二、Eq. 11 存在 self-removal confounding

当前 acquisition information value 是：

[
\Phi_t(M_{t-1})
---------------

\Phi_{t+1}(M_t^*(x,r)).
]

但：

[
\Phi_t \text{ 在 } U_t \text{ 上求和},\qquad
\Phi_{t+1} \text{ 在 } U_t\setminus{x} \text{ 上求和}.
]

因此，即使查询 (x) 得到的 residual 对其他候选完全没有帮助，第二项也会因为 (x) 被移出 pool 而自动降低。

也就是说，所谓 information gain 同时包含了：

1. (x) 自己不再需要被决策的收益；
2. residual 对剩余候选的迁移收益；
3. 新材料改变 convex hull 的收益；
4. retention 重组产生的收益。

第一项不是 downstream memory information，而且 immediate discovery 已经通过

[
\lambda_{\mathrm{disc}}\hat P(s_x=1)
]

计算了一次，因此还可能产生双重计数。当前 Eq. 11 确实直接使用了两个不同候选池上的势函数。

## 正确的比较方式

先定义公共剩余池：

[
V_t^x=U_t\setminus{x}.
]

然后定义：

[
\Delta_t^{\mathrm{info}}(x,r)=
\Phi\left(
V_t^x,H_t,M_{t-1}
\right)
-------

\Phi\left(
V_t^x,
\mathcal T_H(H_t,x,r),
M_t^*(x,r)
\right),
]

其中：

[
\mathcal T_H(H_t,x,r)
]

是查询结果诱发的假设凸包更新。

这样两边在完全相同的候选集合上比较，差异才真正来自：

* residual witness；
* capacity competition；
* causal hull revision。

### 对应代码必须增加的测试

```text
test_information_value_excludes_queried_item_removal
```

构造一个与所有其他候选结构正交、不会修改 hull 的候选。查询它以后：

[
\Delta_t^{\mathrm{info}}(x,r)=0
]

应该严格成立。如果当前实现得到正值，就证明代码确实把 self-removal 当成了信息价值。

# 三、当前 potential 的权重会随着 memory 改变

论文定义：

[
w_M(x)=
\exp\left(
-\frac{|\mu_M(x)-\tau|}{\sigma}
\right).
]

于是 retention 改变 (M) 时，不仅改变区间和预测，也改变了“这个候选有多重要”。

这导致不同 memory 的 (\Phi_t(M)) 实际上在优化不同的加权目标。一个 memory 可能通过把中心 (\mu_M(x)) 推远离边界来降低 (w_M(x))，而不一定真正降低可校准的不确定性。

Proposition 1 所说的 boundary-weighted error 上界，在每个固定 (M) 下可以条件成立；但用它比较两个不同的 (M) 时，评价权重本身已经变化。论文当前的势函数和命题位于 Eq. 7–9。

## 修改为 memory-independent weight

建议使用只依赖 query view 的固定权重：

[
\omega_t(x)=
\max\left{
\omega_0,,
\exp\left(
-\frac{|\hat h_t^0(x)-\tau|}{\sigma}
\right)
\right},
]

其中：

[
\hat h_t^0(x)=\hat E^0(x)-H_t(x).
]

它可以随因果 hull 更新，但不能随待比较的 memory 改变。

对区间

[
I_t(x;M)=
[\underline h_t(x;M),\overline h_t(x;M)]
]

定义：

[
\ell_t(x;M)=
\omega_t(x)
\begin{cases}
c_{\mathrm{FS}}
\mathbf 1{\overline h_t(x;M)>\tau},
&\hat s_M(x)=1,[2mm]
c_{\mathrm{FU}}
\mathbf 1{\underline h_t(x;M)\le \tau},
&\hat s_M(x)=0.
\end{cases}
]

然后：

[
\Phi_t(M;V,H)=\sum_{x\in V}\ell_t(x;M).
]

这样所有 memory 都是在同一个目标上比较。

# 四、不要“选择最方便的一个区间”

当前方法在 prior interval 和多个 witness interval 中，选择使 risk 最小的那个区间。

这要求一个极强条件：

> 所有可能被自适应选择的区间必须同时覆盖真实 residual。

普通 split conformal 通常只给单个测试点的边际覆盖。它不能自动保证：

* 多个 witnesses 同时有效；
* policy 在多个区间中自适应选择后仍有效；
* 多轮 active querying 后仍有效；
* 多个协议 stratum 和 hull 版本下仍有效。

更自然的做法是将全部兼容证据取交集：

[
I_t(x;M)
========

I_t^0(x)
\cap
\bigcap_{i\in\mathcal C_M(x)}
I_{t,i}(x).
]

在所有区间同时有效的事件上，交集仍然包含真实值，而且多个 memory 可以真正共同缩小区间。

如果交集为空，应返回：

> conflict / calibration failure / abstain

而不是选择其中一个看起来最乐观的区间。

这还解决了当前方法的另一个问题：现在每个候选最终只采用一个 witness，因此多个近邻之间几乎没有统计聚合；memory 的作用主要退化为“覆盖更多区域”，而不是通过多条科学证据提高置信度。

# 五、Proposition 1 应该降级或重写

当前命题有三个问题。

## 1. 必须显式定义 simultaneous coverage event

应写成：

[
\mathcal E_t=
\left{
h_t(x)\in I_t(x;M),
\ \forall x\in U_t,
\ \forall M\in\mathcal M_t^{\mathrm{reachable}}
\right}.
]

然后命题表述为：

> Conditional on (\mathcal E_t), the weighted decision error is bounded by (\Phi_t(M)).

如果希望得到概率保证，则必须给出：

[
\Pr(\mathcal E_t)\ge 1-\delta_t,
]

并说明这是通过：

* union-bound 校准；
* transductive simultaneous calibration；
* confidence sequence；
* 或显式假设

中的哪一种得到的。

## 2. (w_{\min}) 会让 Eq. 9 近乎空洞

由于指数权重可以极小：

[
w_{\min}\approx 0,
]

所以：

[
\frac{\Phi_t(M)}{w_{\min}c_{\min}}
]

可能远大于 1。有限池中它形式上大于零，不代表界有实际意义。

使用前面的 clipped weight：

[
\omega_t(x)\ge\omega_0>0
]

才可能改善这一问题。

## 3. (e_t=1) 可以让 bound 自动成立

论文允许 information-seeking override 时加入 (e_t=1)。如果大量查询都属于 information seeking，那么累计界最多只是：

[
R_B\le B+\cdots,
]

几乎没有内容。

我建议当前版本先**删除 discovery-regret 的 Proposition 部分**，只保留严格的 boundary-error proposition。等定义出 exploitation rounds、exploration budget 或统一的 Bayes utility 后，再给累计 regret：

[
\mathbb E[R_B]
\le
\frac{1}{\omega_0c_0}
\sum_{t=1}^{T_B}
\mathbb E[\Phi_t(M_{t-1})]
+
\sum_t\delta_t
+
N_{\mathrm{override}}.
]

即便保留，也必须诚实报告 (N_{\mathrm{override}})，否则该界无法解释。

# 六、区间不能凭空产生两点概率分布

论文写道：

> interval induces an observable approximation
> (\hat p_t(r\mid x))，实现使用两个 boundary-straddling outcomes。

但一个区间只说明：

[
r\in[\underline r,\overline r],
]

并没有告诉你：

[
P(r=\underline r),\qquad
P(r=\overline r).
]

“概率由区间决定”本质上是额外的人为 prior，不是 calibration 结论。Eq. 11 的期望信息价值因此高度依赖一个未验证的概率模型。

有两条可行路线。

### 路线 A：明确做分布鲁棒 acquisition

[
\Delta_t^{\mathrm{rob}}(x)=
\inf_{Q\in\mathcal Q_t(x)}
\mathbb E_{r\sim Q}
\left[
\Delta_t^{\mathrm{info}}(x,r)
\right],
]

其中 (\mathcal Q_t(x)) 是所有支持集位于 residual interval、并满足已知矩约束的分布集合。

### 路线 B：从独立 calibration partition 学 residual CDF

例如按：

* protocol；
* chemical family；
* base uncertainty；
* structure-neighborhood density

拟合条件 residual distribution，并单独报告：

* log likelihood；
* CRPS；
* interval coverage；
* probability calibration。

在真实 residual model 没有建立前，最诚实的写法是将当前方法称为：

> two-scenario lookahead heuristic

不要称它为 calibrated expectation。

# 七、regret 和成本定义还没有完全一致

论文允许可变 query cost：

[
\sum_t C(x_t)\le B,
]

但 Eq. 3 又写成：

[
\sum_{t=1}^{B}.
]

如果 (C(x)\neq1)，(B) 不是轮数。

应改为：

[
T_B=
\max\left{
T:\sum_{t=1}^{T}C(x_t)\le B
\right},
]

以及成本加权 regret：

[
R_B=
\sum_{t=1}^{T_B}
C(x_t)
\mathbf 1
\left{
s_t(x_t)=0
\land
\exists y\in U_t:s_t(y)=1
\right}.
]

还要分开三个指标：

* unstable oracle call；
* false-stable oracle call，即模型预测稳定但实际不稳定；
* information-seeking unstable call，即明确为了信息而查询。

它们现在容易在叙述中混在一起。

此外，dynamic hull 下应该同时报告：

1. query-time causal discoveries；
2. final-hull confirmed discoveries；
3. 后来被新相推翻的 provisional discoveries。

否则一个在当时 hull 上稳定、后来变为不稳定的候选仍可能永远计作“发现”。

# 八、复杂度很可能不是当前写的 (O(n^2K))

直接实现中，每轮需要：

* (n) 个候选；
* 每个候选若干 hypothetical outcomes；
* 每个 outcome 尝试 (K+1) 个 eviction；
* 每个 retention candidate 重算约 (n) 个 query risks；
* 每个 query risk 又可能扫描最多 (K) 个 witnesses。

朴素复杂度因此更接近：

[
O(n^2K^2),
]

而不是 (O(n^2K))。

只有在预先缓存每个 query 的：

* 最优 witness；
* 次优 witness；
* 每张卡的 pointwise risk；
* one-swap delta

以后，才可能将一次 eviction 降至 (O(n))，从而得到：

[
O(n^2K).
]

论文目前写的是“(O(n^2K)) potential evaluations”，这不是足够明确的运行时间说明。

代码里建议明确分成：

```text
BruteForceRetentionSolver
CachedOneSwapRetentionSolver
```

并加入随机小实例上的完全等价测试，而不是只测最终 discovery 数字。

# 九、实验主线需要立即加入 MADE 和 CAL

只用 Matbench Discovery 已经不够支撑“closed-loop benchmark”定位。Matbench Discovery/WBM 是非常好的固定候选池数据；其官方数据说明甚至明确提到，可以把 WBM 构造成 active-learning benchmark，使稳定比例随 WBM 相逐步加入而变化。([GitHub][2])

但 2026 年已经出现专门用于闭环材料发现的 **MADE**，它显式提供预算受限、迭代候选提议、oracle feedback 和策略更新环境。你不一定要采用它的开放生成设定，但 related work 和实验计划都不能忽略。([arXiv][3])

同时必须比较 **Convex Hull-aware Active Learning（CAL）**。它直接以减少凸包不确定性为 acquisition 目标，和你的 boundary-risk acquisition 有高度重叠；你的差异只能是：

> CAL 不研究有限 active witness capacity，以及查询结果与 retention competition 的耦合。

([arXiv][4])

推荐真实实验分两层：

### 固定池层

使用 WBM：

* pool-based、可重复；
* published frozen predictor；
* sequentially revealed DFT energy；
* MP 初始 hull；
* 查询后的 WBM 相逐步更新 hull。

### 闭环环境层

使用 MADE：

* 验证你的 policy 是否可以作为 planner/scorer；
* 测试在不同 chemical-system complexity 下 joint coupling 是否仍存在；
* 和 MADE 自带 planners、random、MLIP ranking 比较。

# 十、synthetic pilot 还需要两个关键实验

## 1. 小规模精确动态规划

当前 offline oracle retention 只优化 retention，而且使用不同 acquisition，所以它不是 joint policy 的真正 oracle upper bound。

对 (n\le 10,B\le4,K\le2) 的二值 residual synthetic environment，可以计算 Bayes-optimal joint policy：

[
V_t(S_t)=
\max_x
\mathbb E_r
\left[
R(x,r)+V_{t+1}(S_{t+1})
\right].
]

然后比较：

* exact Bayes-optimal joint；
* one-step DUALMEM；
* decoupled；
* myopic full history。

最近的 OSL-MR 工作已经用小规模动态规划来判断 single-step policy 与长期最优策略的差距，因此只给一个人为 stress test 会显得不足。([arXiv][5])

## 2. (B\times K) phase diagram

双预算论文不能只报告：

[
(B,K)=(10,2).
]

至少需要：

[
K\in{0,1,2,4,8,\infty},
\qquad
B\in{5,10,20}.
]

报告：

* discoveries；
* regret；
* joint 与 decoupled 的 action disagreement rate；
* information value retained fraction；
* 每轮计算时间；
* joint advantage 出现和消失的区域。

核心主张应该变成：

> coupling 在什么条件下必要？

而不是：

> joint 平均更好。

这也更符合你现有的诚实负结果。

# 十一、related work 和命名都要更新

NeurIPS 2025 的 Online Two-Stage Submodular Maximization 已经研究了第一阶段维护受限集合、后续目标揭示后再从中优化的问题，并给出 online regret，因此你的贡献不能写成泛化的“两阶段有界选择”。差异应放在：

* query 会产生新 evidence；
* dynamic convex hull；
* protocol-compatible residual transfer；
* acquisition 会显式模拟 capacity competition。

([NeurIPS Proceedings][6])

另外，2026 年 6 月已经至少有两篇预印本使用 **Learning What to Remember** 作为主标题，其中一篇还强调 observability-safe online/offline separation。你的可见论文标题已经改成了 *What Should a Discovery Loop Remember?*，这是好事，但 PDF 文件名、项目名和旧标题最好全部同步修改。([arXiv][5])

`DUALMEM` 也已经被多个方法使用，2026 年还有一篇开放世界目标检测工作直接名为 DualMem。建议重新命名，避免检索冲突。([arXiv][7])

# 十二、代码上下一轮必须增加的六项检查

我目前没有可访问的 EviMem-RL 仓库，因此不能独立确认“141 tests passed”或具体实现是否与 PDF 一致。就论文暴露的接口而言，优先加入：

1. **所有轮次的 non-interference property**：两个 oracle world 只要已揭示历史相同，下一动作必须相同，而不仅是首轮相同。
2. **common-pool information gain test**：排除 queried-item self-removal。
3. **variable-cost budget property**：任何路径都不能超过 (B)，最后不足以支付候选时必须停止。
4. **brute-force/cache equivalence**：优化 retention 与穷举 retention 在随机小实例上完全一致。
5. **causal/final hull metric separation**：同一 run 同时输出两套发现指标。
6. **pool permutation invariance**：候选输入顺序改变但 IDs、状态和 RNG 相同，策略结果不能改变。

此外，`acquisition` 最好只接受：

```python
ObservableState
HypotheticalResidualModel
```

而不能接受含 oracle energy 字段的统一 `Material` 对象。类型级隔离比运行时删字段更可靠。

## 最终判断

当前版本已经通过了第一个 GO：

> **有限 retention capacity 确实可能改变最优查询序列。**

但还没有通过论文级 GO：

> **这个作用是否来自一个正确、不可被目标函数漏洞解释、且在真实材料残差中存在的机制。**

下一轮不应该继续增加模块。优先顺序应当是：

1. 修正 Eq. 11 的 common-pool 差分；
2. 将 (K) 改为 active certified witness budget；
3. 固定 boundary weights，并重写 simultaneous-coverage 命题；
4. 去掉“区间自动产生概率”的表述；
5. 做小规模 exact DP 和 (B\times K) 曲线；
6. 同时启动 WBM finite-pool 与 MADE closed-loop pilot。

这六步完成后，这个工作才真正从“精心构造的机制原型”进入“可以被严肃证伪的学术方法”。
